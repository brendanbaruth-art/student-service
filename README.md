# Etudo

Etudo is a Next.js application for a student-to-student services marketplace launching in Paris.

Students can search for everyday help such as moving, tutoring, errands, tech support, pet care, and furniture assembly. Student helpers can present services, prices, availability, reviews, and verification status.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- pnpm

## Local Development

```bash
pnpm install
pnpm run dev
pnpm run lint
pnpm run build
```

## Routes

- `/` homepage
- `/browse` find help
- `/search` search results
- `/students/[id]` student profile
- `/offer` offer a service
- `/signup` onboarding
- `/signin` sign in
- `/verification` student verification
- `/booking` booking request

## Deployment

The app is deployable to Vercel with the default Next.js settings.
